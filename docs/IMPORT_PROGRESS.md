# 2000—2010 真题持续精审进度

本文件是跨会话的唯一进度台账。开始下一篇前必须先核对上一行的交付报告、质量结果和独立提交；完成后立即更新本表。

## 固定交付规则

1. 一次只精审一篇文章；不得把两篇内容合并到同一提交。
2. 每篇执行：原文核对 → 逐句精审 → 全词形覆盖 → 规范词组与链接 → 题目四项解析 → 年度索引 → `npm run quality` → 交付自审 → 独立报告 → 独立提交 → 推送 → 线上核验。
3. 用户不逐篇人工复核；执行者对准确性承担完整复核责任。出现来源或答案不确定时不得提交。
4. 重复词必须链接既有规范词条；新语境只扩充本句义、搭配、出处和统计，不复制词条。
5. 后续文章不得低于 2000 年完形填空与阅读 Passage 1 的密度和完整度。
