## 后续怎么接手

1. 精审新文章时直接采用 `CONTENT_QUALITY_STANDARD.md` 和 `ARTICLE_IMPORT_TEMPLATE.md` 中的 `reading` / `children` 要求；不再制造新的机械讲解。
2. 用户要求改进既有内容时按篇迁移。若未指定下一篇，先接2010 Text 2；迁移前确认原卷和最新Git状态，不混入新文章导入提交。
3. 对该篇逐句找真实阅读障碍：修饰归属、从句边界、非谓语逻辑主语、时态参照、否定与比较、指代或省略。简单句保持短，不强造疑难点。
4. 一边编写一边检查语义；复用已有内容测试中的原文还原、主干词序、子项边界、阅读证据检查。本篇特有风险只加必要断言，不新增重复的整卷审计。
