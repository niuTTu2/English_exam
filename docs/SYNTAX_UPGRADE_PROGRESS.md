1. 精审新文章时采用 `TRAINING_TEMPLATE.md`、`CONTENT_QUALITY_STANDARD.md` 和 `ARTICLE_IMPORT_TEMPLATE.md`；不仅补`reading` / `children`，还补篇章、题目和练习，不制造新的机械讲解。

3. 对该篇逐句找真实阅读障碍：修饰归属、从句边界、非谓语逻辑主语、时态参照、否定与比较、指代或省略。简单句保持短，不强造疑难点。
4. 一边编写一边检查语义；复用已有内容测试中的原文还原、主干词序、子项边界、阅读证据检查。本篇特有风险只加必要断言，不新增重复的整卷审计。
5. 一篇一提交；报告区分“界面已支持”和“正文已重写”，更新本表的实际范围。不要用“所有字段非空”声称所有句子讲清了。

第5句的基准要求：谓语与宾语分开；`already`修饰谓语过程；`for a while`标失去势头的时长；`after`整体标先后；其内部`bewilderingly`与`since 2003`都归属于`rising`。时间线借用前文2008年参照，不凭时态捏造结束日期，不把势头减弱直接等同连续跌价。
