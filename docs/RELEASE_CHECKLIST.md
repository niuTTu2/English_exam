# 发布前人工检查表

候选版本只有全部勾选后才可以提交。每篇独立提交推送后，必须再核验 Cloudflare 公开页面，确认无误才能开始下一篇。

## 来源

- [ ] 年份、试卷类型、文章编号正确。
- [ ] 正文、题干、选项和标点逐字核对完成。
- [ ] 正确答案有可靠来源；不确定项目已单独列出。

## 句子

- [ ] 每句彩色分块能完整还原原文。
- [ ] 主干、层级、语法和逻辑没有漏掉关键从句或修饰关系。
- [ ] 每组成分写清了“哪些词组成、是什么形式、充当什么、修饰谁”，没有只写笼统的 modifier。
- [ ] 时间、地点、条件、原因、让步、目的、方式和程度状语已按本句准确分类。
- [ ] 每个从句写明类型、引导词、内部主语谓语、宾语 / 补语、主句作用和翻译顺序。
- [ ] 先有结构直译，再有准确通顺译文。
- [ ] 长难句翻译没有擅自增加或漏掉否定、比较、指代和逻辑关系。

## 单词与词组

- [ ] 正文、题干、选项的每个英文词都能点击并得到本句信息。
- [ ] 词性、原形、特殊变形正确。
- [ ] 熟词僻义、一词多义和干扰项词义已按本篇需要补齐。
- [ ] 重复词在当前文章/句子显示当前义，没有被其他文章的默认释义覆盖。
- [ ] 每个搭配有中文义和使用规则。
- [ ] 每个词组同时显示原文形式和规范原型。
- [ ] 近义词说明了差别，没有声称可以机械替换。
- [ ] 有“本句可替换”时已展示完整改写句、中文义、语气差别和结构调整；无可靠项未强行生成。
- [ ] 每个“本句可替换”项都能进入有效词条。
- [ ] 所有可点击关联都不是空页面或占位页面。

## 题目与统计

- [ ] 自测空格序号与题号一一对应、顺序正确。
- [ ] 答案、定位句和四个选项错因一致。
- [ ] 题目答案与年份独立核验清单一致，答案来源链接已记录。
- [ ] 年度单词表、词组表和出现次数已包含新增文章。
- [ ] 手机与电脑页面仍保持本句义优先、其他内容折叠。

## 检查结果

- [ ] `npm run quality` 全部通过。
- [ ] 没有删除测试、跳过失败或降低既有规则。
- [ ] 修改范围仅限本篇及其必要索引。
- [ ] 已依据 `docs/CHANGE_REPORT_TEMPLATE.md` 在 `docs/change-reports/` 新建本篇交付报告。
