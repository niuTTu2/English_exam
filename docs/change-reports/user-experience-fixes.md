# 四项体验问题修复

日期：2026-09-16。范围对应`user-experience-audit.md`的P1-1至P1-4，用户明确授权继续修复、提交并沿用既有发布流程。没有导入文章、调整真题答案、修改密码服务、访问真实账号或改写生产学习记录。

## 修改与验收口径

1. 复习词条及自定义清单在旧稳定key之外，另存`articleId + sourceId + headword + label + kind`；各清单与自动复习的来源相互独立，同词多个来源保留并可切换。词卡使用所选出处，不再以当前文章替代来源。旧记录无来源且存在多个匹配时先选择语境；失效或伪造的来源不能直接成为本句语境。选择器和词卡共用一个面板，避免切换时多层弹窗争抢焦点。
2. 复习计数和队列共同使用真实`dueAt`，区分已到期、逾期与全部；正确评分后立即移出已到期。显示今天的具体时间、明天、真实日期或逾期天数，而非原始间隔。时钟不进入学习快照，页面每30秒及回到前台时更新，不因读时间反复上传记录。整句/错题无间隔，保留在已到期。
3. 词组的原文次数、规范结构次数、出处及年度表复用按来源构建并缓存的定位索引。处理缩写结尾句点、弯引号、连字符、空白变化和正则特殊字符；不同句子/题干/选项不会拼成一次出现。`In the U.S.`的年度口径为正文、题干、选项合计2次：`2010-cloze-s9`与`question-201030-option-C`，并在词卡展示这两个出处。不是人为把零改成一。
4. 自测说明从显示题号生成，连续、非连续、单题及空集合都有明确输出；2010 Text 1为21–25题、Text 2为26–30题。完形范围与翻译句数也从当前数据取得，不改变题目内容或计时默认值。

## 兼容性与边界

- v1快照只增加可选`termContexts`，旧`marks`、`termNotes`、`reviewSchedule`、`listItems`及稳定ID不改写；无语境元数据的旧快照不会只因增加空字段就产生一次伪编辑。
- 各语境共享原词条的标签、笔记和复习进度，不另外生成平行词条或独立复习分数。旧记录的多个来源由用户明确选择，不自动以常见含义替代。
- 本次固定统计范围为已精审正文/题干/选项。可配置统计范围、可调计时默认值、展开状态与学习进度解耦，以及其余P2审查建议不在本次四项故障修复内。
- 保留原整份学习快照同步机制，不扩展多设备逐项合并；浏览器验证使用隔离上下文和合成记录，不读取用户的既有浏览器、真实Cookie或生产学习数据。
