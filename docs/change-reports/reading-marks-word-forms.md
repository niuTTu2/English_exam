# 阅读标记接入词汇学习与原形展示

## 范围与实现

用户要求解决两点：阅读中标记的词没有进入学习；词卡和学习卡标题使用原文变形，其他词形遗漏。基线main：`b8c69692234a577e82993bfe85ebbb798d23c3a1`。

- `app/vocabulary-learning/reading-marks.ts`：按原文范围取得正文/题干/选项候选，复用现有记忆和义项合并。新确认与高亮同次保存；旧活动标记在现有迁移入口自动幂等接续，不重置已有计划。取消的范围、整句、整选项不生成单词，精审词组作为独立记忆，自由划选不伪造词组词条。
- `source-marking.tsx`、`exam-page.tsx`、`article-v2.tsx`：注入现有corpus；确认前说明会加入词汇学习，仍隐藏答案与中文词义。误触取消预选无持久化。撤销仅撤回本次且没有后续变化的记忆，新增记忆暂停保留，不删除同步历史；普通取消高亮保留已有学习记录并明确提示。
- `word-forms.tsx` / `.css`、`lexicon.ts`：原形标题与本句词形分列；按需建立既有词形映射的反向索引，展示收录的屈折形式和精审说明。大小写/弯引号不制造重复词形。不写另一套词库、不猜词尾、不把production当成produce的屈折变化。
- `learning-card.tsx`、`article-vocabulary-page.tsx`、`study-app.tsx`：共用标题与词形组件，年度词表点击后的共享词卡同样显示原形；原句、语境词形与sense关联不变。学习正面仍隐藏答案，词形资料在翻面后显示，评分按钮保留在扩展资料之前。
- `vocabulary-learning.tsx`：已标记范围识别记忆中的准确语境标记，不要求再写一套词条级历史标记。

没有新增持久化字段，没有修改原文、句法、答案、文章/句子/题目/词条ID、复习算法、身份系统或部署配置。此次共享词汇UI变更由用户明确要求，旧文章内容和阅读结构仍按冻结基线验证。资料只能显示库中已有的可靠词形，不宣称覆盖所有英语变形。
