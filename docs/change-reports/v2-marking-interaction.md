## 实现

- 做题页提供连续阅读、标单词、标词组、标句子四种明确模式。全文只有一个临时预选，点词/句不保存；蓝色虚线预选和黄色已存标记分开，确认按钮才写入。
- 单词一次点击即选中；词组先选起点再选终点，可重选起点及修正终点；切到另一来源重新选起点，不跨正文/题干/选项拼范围。
- 取消选择/Escape只丢弃预选；已标记列表提供明确来源和取消按钮。添加与移除后支持撤销上次操作，检查记录updatedAt和active，拒绝覆盖之后发生的修改。
- 取消、撤销都保留稳定ID和createdAt；取消使用active:false，不删除同步历史。重复确认相同动作不反向切换。
- 快速读懂的所有英文词可点击，通过精确sourceId打开原有词卡。保留空格、标点和原文词形；点击不加入记忆，关闭不会标记整句。待学、复习仍用共用词卡的显式入口。
- 新逻辑拆到 `app/article-v2/source-selection.ts`、`source-marking.tsx`；未向study-app.tsx继续添加功能，未新增存储字段。
