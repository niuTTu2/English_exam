# 2010 Text 1：主动练习与复盘

## 范围与来源

继续使用用户原卷2010年英语二Text 1（DOCX正文段落116—120），不改原文、题干、选项和答案。为19句添加35项人工编写任务；新增句法、词义、证据、练习四项明确内容状态。其他文章不自动标成完成模板。

## 本轮实现

- 每句先尝试至少一项再看主干和讲解；允许选择“还没找到”，答错不阻止学习。一次显示一个任务，避免再次拉成长屏。
- 任务覆盖谓语、主语范围、修饰归属、指代、从句边界、时态和非谓语逻辑主语。任务ID及语法概念ID稳定，改变题意或答案须增加revision。
- 看提示、查词、打开篇章地图或重做后的正确回答与首次独立正确分开。进度来自实际作答，展开只表示查看。译文自评和自报卡点单独保存，不冒充机器评分。
- 五题可记录定位范围和原句位置，提交后与多句证据对照；未练定位不判错，勾对句子也不代表推理必然正确。
- 错题立即复盘，提示后答对次日复盘，首次正确三日后复盘。概念记录、定位偏差与十二类卡点可返回相应句子/题目。
- Text 1词汇按迁移价值、熟词生义、功能词、结构和专名分层。词卡首屏保留本句义、用法和一个搭配，其余折叠；专名不自动进入背诵队列。
- 新训练记录按事件ID合并；旧页面上传不认识的新字段时，服务端保留已有训练记录。沿用既有版本冲突和备份保护，不改账号或数据库结构，不操作正式个人记录。
