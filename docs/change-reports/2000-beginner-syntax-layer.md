# 2000 年零基础句法层交付报告

## 目标

把原有“彩色分块、逐层拆解、语法提醒”重新组织为基础薄弱者可以按顺序阅读的三步句法说明，同时保持原有精审数据不丢失。

## 本次完成

- 每句先单独显示去除修饰成分后的主干。
- 每个彩色词组进一步说明：原文组合、构成形式、具体句法功能、修饰对象和理解方法。
- 时间、地点、条件、原因、让步、目的、方式和程度等状语使用具体名称，不再只显示笼统的 modifier。
- 从句单独显示类型、引导词、主句作用、内部主语、谓语、宾语 / 补语和翻译顺序。
- 2000 年完形第 1 句作为人工金标准，完整写入条件状语从句和 `between A and B` 后置修饰的详细结构。
- 2000 年既有正文、翻译和提交后的题目分析均可使用新展示层；原有精审层级与语法规则保留在补充折叠区。

## 后续门禁

- 新导入句子不得只依赖旧数据推导，必须人工填写 `beginnerSyntax`。
- 自动测试检查每组成分的形式、功能、修饰对象与说明不能为空。
- 自动测试检查每个从句的类型、引导词、内部骨架、主句作用和翻译顺序不能为空。
- 金标准测试固定检查 `Last year` 为时间状语、`In Japan` 为地点状语，以及完形第 1 句的条件从句内部结构。
