# 2000 年语境词汇与答案复核报告

## 变更范围

- 年份：2000
- 类型：跨文章词汇基础设施与既有答案语义复核
- 目标：稳定复用同一原形词条，同时让不同文章、不同句子的本句义和本句用法彼此独立；新增“本句可替换”展示。

## 语境词汇

- 词条解析现按 `articleId + sentenceId + headword` 选择本句义和本句用法。
- 通用原形、词族、搭配、出现次数继续复用同一稳定词条，不复制平行词条。
- Passage 5 的 `regard` 已验证同篇不同句可分别显示“认可 / 正面看待”和“重视 / 推崇”。
- Passage 3 与英译汉中的 `require` 已验证按文章和句子显示不同宾语结构与用法说明。
- 首批“本句可替换”覆盖完形、五篇阅读和英译汉中的代表性高价值词；每项含完整改写句、中文义、语气差别、直接替换 / 需调整标记及有效链接。
- 首批可替换项只作数据模型与质量基线，不强迫每个词生成替换；后续文章仅在语义和语法都可靠时填写 1—3 项。

## 自动门禁

- 每条句子语境必须指向真实原句和真实原形。
- “本句可替换”必须包含中文义、完整改写句、差别说明和可点击目标。
- 需要调整结构的替换项必须说明调整内容。
- 同一词在跨文章和同篇不同句的本句说明必须可独立覆盖。
- 第 1—30 题答案必须与独立核验清单一致。
