# 单词释义与语境整义分层修复

## 范围与依据

用户指出所有文章都存在教学质量问题，并特别指出点击单词却显示词组或句意。本次是公共查词修复；不计入其他篇的句法迁移完成数。以仓库已收录原文和词条为依据，未改原文、题目、答案、稳定ID或学习记录。

## 实际修复

- 检视35个模块正文中的10367个去重词形/句子组合的解析结果，定位到人工语境字段把宾语、修饰语或整句事件写成词义的问题。此检索用于定位，不是声称10367项都进行了新的人工精审。
- 按具体词义修改2001年完形及两篇阅读、2010年完形/Text 1/Text 2/翻译等已有语境字段。例如 dramatic 是“戏剧性的”，不是“以某种方式结束”；confident 是“确信的”，不是“确信市场已触底”；living room 中 room 是“房间”，客厅是整体搭配义。保留 room 借代满屋听众的另一个语境。
- 单词卡仅复用同为 word 的种子条目，词组卡仅复用 phrase 条目；单词兜底不再读取词组释义表。
- 已审核的句子/来源覆盖仍优先，其次本篇词条；无本篇覆盖时先用共用词义和用法，再使用其他文章的已有知识。此调整避免共用释义被其他篇具体场景抢占；没有按字符串长短自动截断词义。
- 代词的指代、结构词的作用、习语成分的用法保留；近义改写句、搭配和词族没有删除。后续逐篇升级仍需审查本篇语义，不能据此声明全库词义完全无误。
