# 题目与选项精读入口修复

## 范围与来源

用户反馈题目、选项及逐项解析无法查看。核对后确认：题目仅在考场初读页，解析受整篇交卷状态控制，精读缺少题目入口。本次修公共入口并完善2010英语二Text 1第21—25题语言层，不导入其他文章。

原文与答案复用仓库已核验题目、`2010-passage-1-question-analysis.ts`和`2010-passage-1-evidence.ts`，未更改原卷文字、选项、答案或稳定ID。未触及未跟踪的Text 3草稿。

## 实际修改

- 精读可切换正文与题目；考场初读提供直达题目、进入整篇/本题精读的明确按钮，不必交卷才能学习。
- 原题全部选项可读、可查词；各项下分别展开选择依据与语言讲解，证据可回原文。NOT题保留“事实成立，非本题所求”。
- Text 1从4个选项分析补到20个，加5个题干；重点区分过去完成时、过去进行时、被动/状态、`be involved in`、`to a great extent`、`await`与`wait for`、分词修饰与限定谓语等。标题/名词短语只展示短语核心，显式标记8项，不自动猜语法。
- 先给本项句意和读题关键，再按需看完整结构；不把整句翻译作为单词释义。词汇继续使用原题来源ID。
- 从精读题目跳原文后可返回精读，保留已展开内容和滚动位置；原有自测返回路径继续保留。
- 不更新作答、提交、掌握、同步或复习数据模型。其他文章展示既有选项讲解，缺少整句语言分析时如实提示；不声明全库20项同等升级。
