# 2000 年整卷零基础句法复审交付报告

## 基本信息

- 年份：2000
- 范围：完形、阅读 Passage 1—5、英译汉及已有题目提交后分析
- 复审原因：旧版多数句法卡由界面规则推导，可能出现主干释义改写、从句遗漏、嵌套边界错误或成分标签空泛

## 本次完成

- 审计对象：110 个正文/翻译句子 + 72 个题干、选项与答案分析，共 182 个
- 人工确认复杂对象：70 个
- 人工确认从句：98 个，覆盖定语、名词性、状语、比较、关系词省略和状语从句省略
- 主干修正：旧数据中曾补词、换词或释义改写的项目统一改为原文词序删减
- 分块修正：修复原因从句断裂、让步插入吞并主句主语、并列谓语并入地点状语、题干宾语误标等问题
- 展示规则：2000 年从句不再回退到自动推导；没有人工表项即按“人工确认无完整从句”处理

## 代表性纠正

- `p1-s4`：`whose economies` 是 `destroyed` 的宾语；从句主语是 `the war`，不再错误识别为 whose 短语作主语。
- `p2-s24`：`because machines and society did it for us` 保持为完整原因状语从句，不拆成条件片段和孤立谓语。
- `p3-s1`：完整拆出 when 时间从句、what 宾语从句、however 让步从句和 that 真正主语从句。
- `p3-s2`：把主句 `it` 从长让步插入中分离，并拆出 whatever、that 和 on which 三层从句。
- `p4-s14`：`whether...` 与 `how much...` 作为平行间接疑问从句讲解。
- `p5-s8`：完整拆出 What 主语从句、that 表语从句、as 比较从句和 lest 预防性目的从句。
- `p5-s13`：`not mean A, A, but only B` 的三个 that 宾语从句分别显示。
- `p5-s15`：识别 `things stand` 为省略关系词的定语从句。
