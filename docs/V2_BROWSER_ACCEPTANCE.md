# V2 试点浏览器验收入口

评审分支包含2013英语二Text 1。当前记录的自动化检查通过，以下浏览器步骤仍需执行；本文件不是通过证明。

## 启动实际应用

在仓库根目录运行 `node tests/browser-v2/serve-pilot.mjs`，打开 `http://127.0.0.1:5183/__v2-inspection`。

此入口加载原 `vite.config.ts`、实际 `StudyApp`、原有本地API与Service Worker；不复制文章，不使用合成文章或替换词卡。只监听本机127.0.0.1，不创建公网预览，不触发生产迁移。使用独立浏览器测试配置，只建立本机测试记录，不登录正式账号。

入口自身检查：`node tests/browser-v2/serve-pilot.mjs --smoke`。已实际退出0，包装页与应用首页均返回200，首页包含实际应用标题；脚本语法检查、ESLint和`git diff --check`通过。这只确认服务入口，不执行四页浏览器交互。

在应用内选择2013年、阅读Text 1。360px和390px按钮改变同一iframe的布局视口宽度，不重置当前操作。每个状态点击“检查当前页面宽度”，记录时间、视口宽度、文档宽度；还须人工检查词卡等内部滚动容器。此方式不是手机触控模拟。

## 必测路径

| 路径 | 操作和预期 |
| --- | --- |
| 原卷做题 | 6段连续原文、21—25题均保留；无中文、答案或证据。计时可停；原位标记句子、词组范围和选项。 |
| 错因优先 | 第21题选B，其余可选D/B/B/C并提交；第21题先显示所选B与正确A的差别，再显示最小证据与短再判断。 |
| 快速/深度 | 第4句无完整结构或必做任务；第14句“我还是没读懂”默认折叠，展开后可见关系和教育范围。 |
| 来源往返 | 错题证据回到原句再返回该题；题目同义替换词卡回到原始选项；正文词卡回到准确句子。 |
| 词汇搭配 | 检查五类来源；stand out加入独立词组记忆，average的不同语境进入对应sense；打开共用连续学习。 |
| 保存 | 在个人追问输入一条测试笔记；作答、标记、计时、待学和复习入队后刷新，确认恢复。360/390共用同一本机状态，不是两台设备同步测试。 |
| 手机宽度 | 两种宽度分别执行四页、深度、选项、范围标记、追问输入及复习卡；每个状态记录文档宽度不超过视口，检查弹窗不遮挡关闭/返回按钮。 |
| 手机触控 | 在实际手机或受支持的触控模拟环境验证首尾选词、拖动/点击范围和页面滚动；iframe测量不能替代本项。 |

## 离线与账号边界

离线检查从入口的“独立打开完整应用”进入 `/`，不要用验收包装页代替应用首页。联网打开V2四页与词卡，等待应用离线准备完成；关闭网络后重新打开应用，检查缓存页面、词卡和学习记录保存。重新联网后刷新核对记录。开发模式结果须标为开发环境；上线候选仍须在生产构建上重验模块缓存。

账号切换与跨设备保存只使用获准的隔离测试账号或测试环境，不读取或改写正式学习记录。现有合成账号隔离/CAS测试通过，不能代替浏览器真实切换验收。
