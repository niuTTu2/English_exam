# 阅读训练模板与接手路线

当前样板是2010年英语二Text 1。它有19句、35个句子任务、3个篇章回忆任务、原卷5段和5题证据链。用户已确认手机交互完成；Text 2现作为第二篇完整实例，同样覆盖19句、35项句子任务、3项篇章回忆、5段及5题证据。模板状态与页面验收见`SYNTAX_UPGRADE_PROGRESS.md`；其余518句仍是既有内容。不要把统一样式当成统一内容质量。

## 数据在哪里

| 句子怎样组成全文 | `2010-passage-1-guide.ts`、`article-teaching.ts` | 段落作用/关系、全文路线、句子作用、指代目标、时间证据、作者与引语观点分开 |

这几组数据共用稳定句ID，无须复制三套原文。成分边界和解释由编写者判断，不能用关键词推断后直接上线。

## 原卷、段落与题目来源

- 用户提供的原卷是正文、题干、选项、题号、大小写和标点的唯一依据；答案依据单独记录。报告注明可读取的文件、页码或段落位置，已有来源快照与哈希继续复用。网络解析不能静默替换原卷文字。
- Text 1和Text 2的`ArticleContent.paragraphs`都必须保留原卷5段，按顺序覆盖各自19句一次；地图的段落ID与它一一对应。5段、19句、35项任务是这两篇实例的事实，不是其他文章的固定数量要求。不得按教学主题重新切原卷段落。
- 题目语言来源独立于定位句：题干使用`question-<question.id>-prompt`，选项使用`questionOptionSourceId(question, key)`；不得用兼容字段`question.sentenceId`代替题目来源。语言分析的`text`逐字等于当前题干或选项，不能拿正确选项的意思覆盖干扰项。
- 完整阅读模板覆盖每题题干和原卷全部真实选项。Text 1/2各为25份分析；原卷T/F、七选项匹配等须保持实际题型与选项键，不补造四选一。短语显式标`textKind: "phrase"`，不虚构整句谓语；短语内部有真实从句时仍按实际边界解释。

## 正文、词卡与知识来源隔离

- 正文分析保存原句、主干、成分、从句与翻译；单词卡保存当前词形、稳定原形、当前词性、本句义和用法；词组卡另存`sourceExpression`与`canonicalForm`。单词`contextualMeaning`不装入整个搭配的译义，句子事件放在`use`或正文讲解。
- 每次查词以`articleId + sourceId/sentenceId + headword`查当前语境；正文、题干、各选项均走自己的来源。原形、屈折词形和派生词族继续分层统计，不因新增语境复制平行规范条目。
- 词性、本句义、用法、结构说明和搭配都要核对来源。不能只修正释义，却让`getWordKnowledge`或旧词条合并又带回另一句的结构、搭配和语法作用。当前语境已明确的专属字段优先；通用知识可复用，但不能冒充当前句用法。
- 例如Text 2正文的`more than men`与题目中的`more research`、`more talkative`分别比较数量或程度，词卡不能全部沿用同一个词性标签；`home`、`share`、`given`同样按来源判断。正文`phrase`和题干中用于说明被考短语的`phrase`也不能共用未经核对的本句用法。
- 对正文、题干、选项的全部实际可点击词形扫描；同时核对已标注词组和词卡搭配链接能打开中文义、结构规则与必要例句。无可靠近义替换或词族内容时可以不列，不增加“每词几条结构”“每句几项替换”的数量门槛。自动字段检查不能证明语义没有串句，重点歧义须保留具体来源的回归例子。

## 一篇怎样完成

1. 先核对仓库实际状态和用户原卷，保存原有句/词/题ID。原卷不足时停止该篇，不猜分段、答案或缺字。
2. 随录入完成语义自审：简单句一个关键点；中等句解释修饰归属；复杂句才完整拆嵌套、非谓语执行者、指代和时间关系。先讲“这几个词在说明谁”，再给术语。
3. 同时补篇章地图、题目证据和短任务。篇章图不泄露到初读；多句题不再只挂单句。题目错误类型要解释具体偷换了什么；NOT题保留“事实成立，非本题所求”。
4. 复用原形词条，按文章/句子补新义、新搭配和可替换表达；词形/原形/词族各算各的。不要把完整短语译义写进单词contextualMeaning。
5. 完成范围写入teachingStatus和升级台账；按`RELEASE_CHECKLIST.md`跑一次必要检查、写一份报告、独立提交推送。不为节省token省略判断，也不为显得精细反复审核无变化文章。

## 训练与记录的边界（2026-09-18更新）

- 简单句保留短选择题；复杂句至少一个`range`（连续范围）、`link`（逐项连接）或`order`（主干/翻译顺序）任务。不按每句字数凑解释。选择题和词块池轮换位置，同一次作答保持稳定。
- 每句先尝试至少一个任务，答错也可看讲解；篇章地图先尝试三项回忆。题意、答案或作答形式变化必须增加revision，保留旧事件但不冒充新题通过。
- 提示按任务与当前轮次记录：`hintWords`只列真正泄露该任务答案的查词入口；`mapRevealsAnswer`只标与地图直接相关的任务。人名不能污染谓语题。
- 同题反馈算本轮提示；跨任务反馈只有`leaksToTaskIds`或跨来源的`leaksToTasks`明确声明时才传播。历史答过不等于本次借助提示。未活动30分钟后进入新轮次，旧答案默认隐藏；刷新仍保留当前轮次。
- 作答事件保存任务ID/revision、轮次、时间、提示类型和来源。旧版粗粒度辅助记录无法可靠还原，保留原记录，不反推独立成绩。
- 三个数字分开：训练完成（所有任务均尝试过）、独立掌握（当前版本任务最近均无相关提示答对）、今日待复习（到期任务）。地图复习计入任务数，不计入正文19句分母。
- 间隔从实际事件重算：错/辅助1天；到期独立连续正确3、7、14、30天；提前反复练习不晋级。能在新轮次恢复独立正确，不永久惩罚历史错误。
- 定位评分使用`locationPolicy`：允许多条证据路径，每条区分必需证据组、允许补充句和数量上限，同时核对覆盖、精确率及范围。全选全文不得通过；未匹配参考不等于语义必然错。原题成绩与定位分开。
- 定位在连续原文中点整句；交卷后可重新练习。`locationAttempts`按UUID保留每次选句、规则版本和当时结果，复盘不覆写初次记录。旧草稿保留时明确原提交时间未知。
- 训练与定位事件沿用同步兼容保护，不清空笔记、标记和历史。译文是自评，不能算机器语义掌握。
- 复盘卡含年份、篇目、句序、原句开头、上次错误与日期；可以按到期/仍错/曾借助提示、概念和篇目筛选，直接打开对应任务。
- 词汇优先级是编辑建议，不会因为打开词卡自动进队列。专名建议不单独背，功能词建议回到句法任务；仍保留自愿标记。
- 题目证据跳转后保留返回原题按钮、选项上下文、已展开证据区和滚动位置。精读内层称“纯净原句｜查词｜看结构”。
- 精读另有“正文精读｜题目与选项”入口，不要求先答完整卷。题干与原卷全部选项始终可见，选择依据和语言讲解就地折叠；看解析不能写入作答、提交或掌握记录。考场初读仍在主动进入精读或交卷后才展示答案。题目往返记住出发模式，不能把精读用户送回自测。旧篇缺少整句拆解时如实提示，不生成占位讲解。

## 提示入口、反馈依赖与版本

`hintWords`对应用户实际打开卡片时传入的词形或整段词组标签，当前匹配只忽略大小写，不会自动将词形归一为词典原形。例如点击`interviewed`不能只登记`interview`；整段`is wreaking havoc with marriage`与其中单词是不同入口。编写任务时核对真实单词点击和词组点击，只有卡片内容确实泄露答案才登记；不能因为词形出现过就把整句所有任务标为辅助。

反馈依赖是有方向的：查看A的反馈泄露B，记录在A的`leaksToTaskIds`；跨正文/地图来源则用A的`leaksToTasks`写明B的来源ID与任务ID。A→B不自动意味着B→A，也不沿B→C自动扩散。相互泄露时分别声明两条关系；目标必须存在。地图自身的3项任务也要检查答案、连续原文证据、概念与反馈依赖，不能因为不计入正文句数而漏验。

| 修改内容 | 版本处理 |
|---|---|
| 题意、答案、可选项含义、任务形式或判分规则变化 | 增加该任务`revision`，稳定任务ID保留 |
| `hintWords`、`mapRevealsAnswer`或反馈依赖变化，导致同一次操作是否算独立作答改变 | 增加受影响目标任务的`revision`；仅改发出反馈任务的版本不足以失效旧目标成绩 |
| 定位证据路径、必需组、允许补充句、选句上限或范围规则变化 | 增加该题`locationPolicy.revision`，历史记录保留当时规则版本与结果 |
| 修正标点或说明错字，未改变题意、证据含义、答案和辅助判定 | 不为纯编辑变化机械升版；报告说明修改范围 |

旧事件不删除、不覆盖，不把旧版答对或辅助判断倒算成新版独立掌握。新增任务用新稳定ID，现有任务修订不能靠换ID抹去历史。

## 题型适配与后续范围

`quality:content`覆盖原文还原、主干词序、父子边界、第一层/详情一致、篇章与题目证据引用、任务和已完成状态；通用门禁对实际声明的完成层执行。完整阅读篇才要求全题干/选项语言层；只完成语法层时不能连带标记词汇、证据和练习完成。测试只能发现结构性矛盾，不能代替英文理解。

2026-09-18用户确认手机交互完成后，Text 2已补齐新模型、篇章/题目/练习及25个题目来源的语境词汇，见该篇报告。本轮最新接续是先完成Text 2补强，再把完整规范按题型应用到所有已导入文章：从2010 Text 3继续，再到其他阅读、完形、Part B、翻译、2011/2012及2000/2001既有内容。每篇独立提交、独立记录实际完成层，不能一次把未迁移内容标为完成。未导入年份仍须用户可靠原卷。

| 题型 | 共用层 | 需按题型编写的训练与证据 |
|---|---|---|
| 阅读选择题 | 原文、精确关系、词卡隔离、翻译与记录版本 | 原卷段落、篇章地图、全部题干/选项语言、答案证据、多路径定位及主动任务 |

| 新题型/匹配 | 原文、精确关系、词卡隔离 | 衔接线索、段落关系、真实匹配候选与排除依据，不改成四选一 |
| 翻译 | 原文、精确关系、词块对应、译文分层 | 意群、语序、指代与译文自评；整篇翻译仍按原卷整篇作答，不强造选择题与答案分数 |
| 写作 | 原要求阅读、用词结构与来源 | 审题、任务约束、提纲、原图数据与表达；不把范文拆成阅读题或冒充机器语义评分 |

当前`teachingStatus`四层全部完成实例是Text 1/2的完整阅读模板；其他文章可先逐篇完成语法等独立层，只有相应题型的数据、训练和验收落实后才能声明其余层完成。后续全库应用保留按篇独立提交与记录，不把阅读选择题模型强套给所有题型，也不把公共组件升级当作全库内容升级。

### 非客观题的完成门禁

翻译和写作没有客观选择题，`evidence=true`不能因`questions=[]`而自动通过。门禁核对实际`translationTasks`或`writingTasks`，任务中的原句ID、原文和顺序须与文章来源一致。翻译保留单句/整篇作答边界与原卷段落，作答原文、参考译文和定位说明齐全；写作保留原指令、篇幅要求、任务约束、提纲、参考范文双语说明、自查标准及原图数据。范文不进入原题句子及考试词频。

两类仍须为每句原文或指令配置1—3项真实主动任务，检查提示、版本和可操作范围。翻译选段与写作指令不强造阅读文章地图；若确有地图，则完整执行地图来源与三项回忆检查。阅读和完形仍要求原段落及地图。完形的选项理由可用“语法不符”“搭配不符”“语境不符”准确标明错误，仍保留真实选项及来源证据，不把“查看参考译文/范文”当作机器语义评分。
